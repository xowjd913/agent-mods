# 설정 창 (settings)

탭 줄의 `설정` 버튼 하나로 여는 설정 창입니다. GitHub·Claude 계정 고르기, 이름 규칙(프로필) 맞추기, UI 모드 글자 크기 정하기, 설치된 모드 보기를 한곳에 모읍니다.

## 사용법

탭 줄 오른쪽의 `설정`을 누르면 창이 하나 뜹니다. 이미 떠 있으면 같은 창이 바뀔 뿐 새로 늘지 않습니다. 왼쪽 목록에서 칸을 고릅니다.

| 칸 | 내용 |
| --- | --- |
| `계정` | [gh-accounts](gh-accounts.md)를 그대로 보여 줍니다. **GitHub 계정(저장소별)과 Claude 계정**을 고르고, 기본 계정, 계정 추가, 규칙, gh-account 도구 설치가 모두 여기서 됩니다. |
| `모드` | 이 저장소가 제공하는 모드와 내 PC에 설치됐는지를 보여 주고, 창에서 바로 설치·제거합니다. |
| `규칙` | 리더·PO 보고를 알아보는 이름 규칙(프로필)을 봅니다. 규칙 고르기(`PO 규칙`/`규칙 없음`)와 이름 칸을 고쳐 저장합니다. 아래 "규칙 칸"에 있습니다. |
| `UI 모드 글자 크기` | UI 모드(inbox) 글자를 **Herdr 글자 크기에 맞추거나**(기본), 10~24px로 **따로 정합니다.** 아래 "글자 크기 칸"에 있습니다. |

- 모든 칸의 내용은 오른쪽에 같은 여백(24px, `INSET_R`)을 둬서 드롭다운·× 버튼·추가 버튼이 스크롤바에 붙지 않습니다(계정 칸은 gh-accounts 가 같은 값으로 맞춥니다).
- 내용 아래에는 여백 칸(24px)이 있고, 창 높이는 720입니다. 마지막 줄이 창 아래에 붙지 않습니다(내용 모드는 그대로 두고 설정 쪽 레이아웃에서 해결).
- 창 위쪽 막대를 끌면 창을 옮기고, `✕`로 닫습니다.
- 마지막으로 본 칸을 기억해 두었다가 `설정` 버튼으로 다시 열면 그 칸으로 엽니다. 기억이 없으면 `계정` 칸입니다.

### 규칙 칸

규칙(#126)은 [인박스 계약 §9](../inbox-contract.md#9-프로필)의 프로필(`profile.json`)을 창에서 고치는 칸입니다. "PO 규칙이 없는 사람은 `규칙 없음`, 자기 규칙이 있는 사람은 자기 이름에 맞게" 맞추는 것이 목적입니다.

- **지금 상태**: 쓰고 있는 프로필 파일 경로(`HERDR_INBOX_PROFILE`이 있으면 그 파일), 파일이 있는지, 지금 적용되는 규칙(`PO 규칙`/`규칙 없음`)과 **이유**(파일에 적혀 있음 / 파일은 있는데 규칙 값이 없어 PO 규칙 / 파일 없음 + PO 스크립트가 이 PC에 있음 / 파일 없음 + PO 스크립트 없음)를 보여 줍니다.
- **규칙 고르기**: `PO 규칙`·`규칙 없음`을 누르면 아래 칸이 그 규칙의 기본값으로 채워집니다. 기본값과 같은 칸은 파일에 적지 않습니다.
- **고칠 수 있는 칸**: 배치 스크립트(`arrangeScript`), 에이전트 이름 패턴(`agent.name`), 역할 라벨(`agent.role`), 탭 제목 머리말(`agent.titlePrefix`), 이름에서 뗄 앞머리(`agent.strip`), 허브 역할(`hub.role`), 허브 폴더 이름(`hub.id`). 종류 별칭·라벨 이름 등 나머지 키는 이 창이 건드리지 않고 **파일에 있던 그대로 둡니다**(모르는 키도 그대로).
- **저장**: 창이 도우미(`rules.cjs`)를 Herdr의 `exec`로 돌립니다. 도우미는 ① 저장할 내용을 inbox와 같은 로더(`profile.cjs`)로 **먼저 검사**하고(틀리면 파일은 그대로, 이유만 보여 줌) ② 옛 파일을 `profile.json.bak`으로 백업하고 ③ 임시 파일을 만들어 한 번에 바꿔치기합니다. 값이 너무 길거나 정규식이 깨졌으면 거절합니다.
- **깨진 프로필**: 파일이 JSON이 아니거나 모르는 버전이면 이유를 보여 주고 **저장은 막습니다**(덮어쓰기로 내용을 잃지 않도록). `기본값으로 되돌리기`(확인 한 번)가 그 파일을 `.bak`으로 옮깁니다.
- **잠금**: 저장·되돌리기도 모드 칸과 같은 공유 잠금(`settings.busy`)을 씁니다. 도는 동안 다른 설치·저장은 시작되지 않습니다.
- **저장한 뒤 다시 시작해야 하는 것**: 창이 알려 줍니다. 이 창은 저장 직후 이름을 공유 상태(`inbox.names`)에 올려, **같은 Herdr에서 켜져 있는 탭 줄·리더 탭 등은 다음 새로고침 때 따라옵니다.** 바뀌지 않는 패널이 있으면 Herdr를 다시 시작하세요. 쓰기 도구(`inbox-write`)와 PO 훅은 실행할 때마다 프로필을 읽으므로 따로 할 일이 없지만, **이미 켜진 PO 세션은 다시 시작해야** 새 이름을 씁니다. 배치 스크립트는 이미 만든 배치에는 영향이 없습니다.
- **`inbox`를 설치하지 않은 경우**: 예전에는 이름이 코드의 `PO` 기본값으로 고정이었습니다. 이제 이 창이 읽은 규칙을 `inbox.names`에 올리고, `tabs-mine`도 시작할 때 값이 비어 있으면 도우미로 한 번 읽어 올립니다. 그래서 `inbox` 없이도 프로필(또는 `규칙 없음`)을 따릅니다. 도우미를 못 돌리면 조용히 `PO` 기본값으로 남습니다.

### 글자 크기 칸

UI 모드(inbox)의 글자 크기를 정하는 **유일한 자리**입니다(#126, #80). 글자 크기 조절은 다른 곳에 따로 없습니다.

- **Herdr 글자 크기 따르기**(기본): UI 모드가 Herdr의 글자 크기 설정(`font_size`)을 그대로 따릅니다. 13이면 기존 모양이고 14·16이면 같은 비율로 커집니다.
- **직접 정하기**: `직접 정하기`를 누르면 `−`/`+` 단추로 **10~24px**를 고릅니다(처음 값은 지금 쓰는 크기). 이 값이 Herdr의 글자 크기보다 우선합니다. 한도(10, 24)에서는 그쪽 단추가 눌리지 않습니다. `Herdr 글자 크기 따르기`를 누르면 직접 정한 값을 지우고 다시 Herdr 값을 따릅니다.
- **지금 상태**: 위쪽 상자에 `지금 Herdr 글자 크기`와 UI 모드가 실제로 쓰는 크기(어느 쪽을 따르는지 포함)가 나옵니다. Herdr 값을 읽지 못하면 `알 수 없음`으로 보이고 13px로 계산합니다.
- **미리보기**: 고른 크기로 보이는 한 줄이 그 아래에 있어 눌러 보면서 맞춥니다.
- **다시 시작하지 않아도 됩니다.** 값은 공유 상태 `settings.uiFontSize`(숫자, 따르기면 비어 있음)에 저장되고, Herdr가 이것을 설정 폴더에 보존하므로 **다시 켜도 남습니다.** inbox는 그림을 그릴 때(최대 1초에 한 번)와 2초 타이머에서 이 값을 읽어 바뀌면 바로 다시 그립니다.
- **잘못된 값은 무시합니다.** 숫자가 아니거나 10~24 밖이면(저장된 값이 깨졌어도) 직접 정한 값이 없는 것으로 보고 Herdr 값을 따릅니다. 계산은 `fontScale(Herdr 설정, 직접 값)` 하나(inbox와 같은 코드)이고, 시험이 두 복사본이 같은지 확인합니다.
- 이 창이 2초마다 Herdr의 글자 크기를 다시 읽어, 앱에서 글자 크기를 바꾸면 이 칸의 `지금 Herdr 글자 크기`도 따라 바뀝니다.

### 모드 칸

- 모드마다 이름, 한 줄 설명, `기본`/`추가`, 설치 여부가 한 줄로 나옵니다. `새로고침`으로 다시 읽습니다.
- **설치 안 된 모드는 `설치`, 설치된 추가 모드는 `제거`** 버튼이 있습니다. `제거`는 확인(`제거`/`취소`)을 한 번 거칩니다. 기본 모드(`settings` 자신 포함)는 제거 버튼이 없습니다.
- 누르면 **내가 설치할 때 쓴 것과 같은 출처의 설치기**를 Herdr의 `exec`로 돌립니다. `main`으로 못 박지 않습니다. 설치기가 설치할 때 `settings` 모드 폴더에 출처를 `.source.json`으로 적어 두고, 이 창이 그것을 읽습니다.
  - **저장소를 받아 돌렸다면(local)**: 그 저장소의 설치 스크립트가 아직 있으면 그대로 돌립니다(`sh <경로>/install.sh --add <모드>`, 제거는 `--remove`, Windows는 `install.ps1 -Add/-Remove`).
  - **원격 한 줄로 설치했다면(remote)**: 기록된 ref로 한 줄을 돌립니다. `AGENT_MODS_REF=<ref>`를 넘기고 그 ref의 `install.sh`/`install.ps1`을 받습니다. 기본 `main`입니다.
  - **기록이 없거나(예전 설치) 알 수 없거나 저장소가 없어졌다면**: 돌리지 않고 `명령 복사`만 보여 줍니다. 복사되는 명령은 `main` 원격 한 줄입니다.
  - 이 Herdr 설정 폴더를 `HERDR_APP_HOME`으로 넘깁니다.
- 확인 줄(`설치`/`제거` 모두)은 설치기가 **설치된 모드 전체를 그 출처에서 다시 복사한다**는 것과 출처 한 줄을 알려 줍니다. 창 위쪽에도 출처가 한 줄로 보입니다.
- 도는 동안 "설치하는 중…/제거하는 중…"이 보이고 다른 버튼은 눌러도 돌지 않습니다. 이 잠금은 창이 아니라 공유 값(`settings.busy`, 10분 뒤 만료)에 있어서 창을 닫았다 다시 열어도 두 번째 실행이 시작되지 않습니다. 끝나거나 실패하면 풀립니다. 끝나면 설치 여부를 다시 읽고 결과 한 줄을 보여 줍니다.
- 설치기가 거절하거나(예: 다른 모드가 기대는 모드 제거) 실패하면 마지막 출력 줄과 함께 `명령 복사` 버튼이 나옵니다. 터미널에서 직접 돌릴 수 있습니다.
- **바꾼 뒤에는 Herdr를 다시 시작하세요.** 창이 알려 줍니다.
- 이 목록은 설치기의 모드 목록을 손으로 옮긴 것입니다. 어긋나지 않는지는 자동 시험이 확인합니다.

## 필요한 것

- 함께 설치되는 모드: `gh-accounts`(계정 칸). `tabs-mine`을 설치하면 이 모드도 함께 들어갑니다.
- 규칙 칸은 설치기가 `settings` 폴더에 함께 복사하는 `rules.cjs`·`profile.cjs`가 있어야 하고, `node`가 필요합니다.
- 아직 실제 Herdr 화면에서는 눌러 보지 못했습니다(시험은 소스 검사, 화면 구성, 그리고 임시 폴더에서 돌린 도우미의 읽기·저장·되돌리기까지). 규칙 칸의 입력칸 모양·저장 뒤 다른 패널이 따라오는지는 미확인입니다. 글자 크기 칸도 마찬가지로 실제 화면에서 단추를 눌러 UI 모드 글자가 바로 바뀌는지, 값이 Herdr를 다시 켠 뒤에도 남는지, 미리보기 줄의 모양은 확인하지 못했습니다(시험은 값 계산·단추 동작·저장 호출까지).

## 설치

기본 설치에 들어 있습니다. 탭 줄의 `설정` 버튼이 이 모드를 열기 때문에 `tabs-mine`과 함께 갑니다.

```sh
sh herdr/install.sh --add settings
```

```powershell
./herdr/install.ps1 -Add settings
```

`tabs-mine`이 이 모드에 기대므로, 다른 모드가 기대는 동안에는 `--remove settings`가 거절됩니다.

빼는 방법과 다른 옵션은 [모드 골라 설치](../../herdr/README.md#모드-골라-설치)에 있습니다.
