# 설정 창 (settings)

탭 줄의 `설정` 버튼 하나로 여는 설정 창입니다. GitHub 계정 고르기와 설치된 모드 보기를 한곳에 모읍니다.

## 사용법

탭 줄 오른쪽의 `설정`을 누르면 창이 하나 뜹니다. 이미 떠 있으면 같은 창이 바뀔 뿐 새로 늘지 않습니다. 왼쪽 목록에서 칸을 고릅니다.

| 칸 | 내용 |
| --- | --- |
| `GitHub` | [gh-accounts](gh-accounts.md)를 그대로 보여 줍니다. 저장소별 계정 고르기, 기본 계정, 계정 추가, 규칙, gh-account 도구 설치가 모두 여기서 됩니다. |
| `모드` | 이 저장소가 제공하는 모드와 내 PC에 설치됐는지를 보여 줍니다. |
| `규칙` | 준비 중입니다(#124). 눌러지지 않습니다. |
| `Claude 계정` | 준비 중입니다(#123). 눌러지지 않습니다. |
| `UI 모드 글자 크기` | 준비 중입니다(#103). 눌러지지 않습니다. |

- 창 위쪽 막대를 끌면 창을 옮기고, `✕`로 닫습니다.
- 마지막으로 본 칸을 기억해 두었다가 `설정` 버튼으로 다시 열면 그 칸으로 엽니다. 기억이 없으면 `GitHub` 칸입니다.

### 모드 칸

- 모드마다 이름, 한 줄 설명, `기본`/`추가`, 설치 여부가 한 줄로 나옵니다. `새로고침`으로 다시 읽습니다.
- **모드를 켜고 끄는 것은 창에서 하지 않습니다.** 대신 그 모드에 맞는 명령을 복사 버튼으로 가져갈 수 있습니다.
  - macOS·Linux: `sh herdr/install.sh --add <모드>` / `--remove <모드>`
  - Windows: `./herdr/install.ps1 -Add <모드>` / `-Remove <모드>`
- 창이 모드를 켜고 끄지 않는 까닭: 설치기(`install.cjs`)는 모드 폴더에 함께 복사되지 않아 앱 안에서 돌릴 수 없고, 레이아웃과 파일을 고치므로 명령을 눈으로 확인하고 직접 실행하는 편이 안전해서입니다. 모드를 바꾼 뒤에는 Herdr를 다시 시작하세요.
- 이 목록은 설치기의 모드 목록을 손으로 옮긴 것입니다. 어긋나지 않는지는 자동 시험이 확인합니다.

## 필요한 것

- 함께 설치되는 모드: `gh-accounts`(GitHub 칸). `tabs-mine`을 설치하면 이 모드도 함께 들어갑니다.
- 아직 실제 Herdr 화면에서는 눌러 보지 못했습니다(시험은 소스 검사와 화면 구성까지).

## 설치

기본 설치에 들어 있습니다. 탭 줄의 `설정` 버튼이 이 모드를 열기 때문에 `tabs-mine`과 함께 갑니다.

```sh
sh herdr/install.sh --add settings
```

```powershell
./herdr/install.ps1 -Add settings
```

`tabs-mine`이 이 모드에 기대므로, 다른 모드가 기대는 동안에는 `--remove settings`가 거절됩니다.

빼는 방법과 다른 옵션은 [모드 골라 설치](../../herdr/README.md#모드-골라-설치)에 있습니다.
