# 경로 메뉴 (path-menu)

터미널의 파일 경로를 Cmd+클릭(Windows·Linux는 Ctrl+클릭)하면, 누른 자리에 폴더 열기·파일 열기·경로 복사 메뉴를 띄웁니다.

```text
  수정한 파일은 src/components/header.tsx 입니다.
                ▲ Cmd+클릭
              ┌────────────────────────┐
              │ src/components/header… │
              │ 폴더 열기              │
              │ 파일 열기              │
              │ 경로 복사              │
              └────────────────────────┘
```

*메뉴 모양을 글자로 그린 스케치입니다. 실제 화면은 Herdr 테마 색을 따릅니다.*

## 사용법

- **위치**: 터미널
- **맞는 사람**: 에이전트가 알려 준 파일 경로를 바로 열고 싶은 사람

### 메뉴 항목

- `폴더 열기`: Finder·탐색기에서 그 파일을 골라 보여 줍니다. 폴더 경로면 그 폴더를 엽니다.
- `파일 열기`: 기본 앱으로 엽니다. 폴더에는 이 항목이 없습니다.
- `경로 복사`: 경로를 클립보드에 넣습니다.

### 열 수 없는 경로

- 없는 경로는 알림을 띄우고, 그 위로 올라가며 처음 있는 폴더를 메뉴 머리에 보여 주며 `폴더 열기`를 줍니다.
  - 디스크 뿌리(`/`, `C:\`)와 홈 폴더(또는 그 위)까지는 올라가지 않습니다.
  - 그 아래에 있는 폴더가 하나도 없으면(예: 화면의 웹 경로 `/api/v1/users`) 원래 경로와 `경로 복사`만 보여 줍니다.
- 원격 터미널의 경로도 `경로 복사`만 됩니다.
- 웹 주소(URL)는 건드리지 않아 Herdr 원래대로 열립니다.

### 두 줄 이상으로 나뉜 경로

Claude Code처럼 화면 안에서 스스로 줄을 바꾸는 앱은 긴 경로를 잘라 다음 줄에 이어 씁니다. 옆에 패널이나 상자 테두리(`│`)가 있어도 마찬가지입니다.

- 누른 조각이 그 줄 글의 끝(또는 처음)에 있으면 다음(또는 앞) 줄 글과 이어 붙여 봅니다.
  - 줄 끝의 공백, 테두리, 그 뒤 패널은 보지 않습니다.
- 어느 조각을 누르든 이어 붙인 경로가 실제로 있으면 그 경로로 메뉴를 엽니다.
- 이어 붙인 경로가 없으면 누른 조각만 씁니다.
- 아래 조각(앞 줄과 이어 붙는 쪽)을 눌렀는데 그 조각 자체가 있는 경로면 그것을 씁니다.
  - 예: `ls -1F` 결과에서 `herdr/` 다음 줄의 `README.md`를 누르면 `herdr/README.md`가 아니라 `README.md`를 엽니다.
- 같은 조각이 화면 여러 곳에 있어 어느 것인지 모호하면 누른 조각만 씁니다.
  - 예: 목록의 `- README.md`와 긴 경로 끝에서 잘린 `README.md`가 함께 보일 때

### 오류

- 열기·복사 명령이 실행되지 않거나 오류 코드로 끝나면 오류 알림을 띄웁니다.

## 필요한 것

- 함께 설치되는 모드: 없음
- macOS: 따로 필요한 것 없음(`open`, `pbcopy`)
- Windows: 따로 필요한 것 없음(탐색기, PowerShell)
- Linux: `xdg-open`과 `xclip` 또는 `wl-copy`
  - Linux에서 `폴더 열기`는 파일을 골라 보여 주지 않고 상위 폴더를 엽니다.

## 설치

추가 모드라 기본 설치에는 들어가지 않습니다.

```sh
curl -fsSL https://raw.githubusercontent.com/xowjd913/agent-mods/main/herdr/install.sh | sh -s -- --add path-menu
```

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/xowjd913/agent-mods/main/herdr/install.ps1))) -Add path-menu
```

- 설치하면 레이아웃 맨 위 `link_handlers`에 `path-menu`를 더합니다.
- Herdr가 개인 레이아웃의 `link_handlers`에 스스로 더한 `path-menu`는 `--remove` 뒤에도 남습니다. 필요하면 그 레이아웃에서 직접 지워 주세요.

빼는 방법과 다른 옵션은 [모드 골라 설치](../../herdr/README.md#모드-골라-설치)에 있습니다.
