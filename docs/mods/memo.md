# 메모 (memo)

오른쪽 패널에서 메모를 쓰고, 마음에 드는 메모는 버튼 하나로 PO 터미널에 보냅니다. 메모 하나는 **폴더 안의 `.md` 파일 하나**라서, 다른 편집기로 고쳐도 되고 폴더째 백업하거나 동기화해도 됩니다.

- **이런 사람에게**: 떠오른 생각을 바로 적어 두었다가 PO에게 "이거 해 줘"로 넘기고 싶은 사람.
- **어디에 저장되나**: 내가 고른 폴더. 처음에는 `~/Documents/Herdr Memos`(Windows는 `%USERPROFILE%\Documents\Herdr Memos`)입니다. 폴더가 없으면 첫 메모를 저장할 때 만듭니다.
- **GitHub·Google Drive 업로드는 하지 않습니다.** 이 모드는 어떤 클라우드에도 로그인하거나 올리지 않습니다. 다만 Google Drive 데스크톱 앱의 동기화 폴더(예: `내 드라이브` 안의 폴더)를 메모 폴더로 고르면 Drive 앱이 알아서 올려 줍니다. OneDrive·iCloud Drive도 같은 방식입니다.

## 사용법

### 목록

패널을 열면 메모 폴더의 `.md` 파일이 **고친 시각이 최근인 순서**로 나옵니다. 위 칸에는 제목, 아래 칸에는 본문 앞부분이 보입니다.

- **제목**은 글 안의 첫 `# 제목` 줄입니다. 없으면 첫 줄이 제목입니다. 비어 있으면 `제목 없음`입니다.
- 폴더 안에서 다른 프로그램으로 파일을 더하거나 고쳐도 목록은 몇 초 안에(또는 새로고침을 누르면 바로) 따라옵니다.
- 맨 위 폴더 줄에서 `폴더 바꾸기`로 폴더를 고르고, `기본 폴더로`로 되돌립니다. 폴더 줄에는 Google Drive 안내가 함께 보입니다.

### 쓰기·고치기·지우기

- `새 메모`: 빈 글쓰기 화면이 열립니다. 저장하면 `2026-11-27 1530 제목.md` 같은 이름의 파일이 생깁니다. 파일 이름에 못 쓰는 글자(`\ / : * ? " < > |`)는 공백으로 바뀌고, **같은 이름이 있으면 `(2)`를 붙여 새로 만듭니다. 기존 메모 파일을 덮어쓰지 않습니다.**
- 목록에서 메모를 누르면 고치는 화면이 열립니다. 저장해도 파일 이름은 그대로입니다.
- 고치는 사이에 **다른 곳에서 같은 파일이 바뀌었다면** 저장하지 않고 알려 줍니다. `내 글로 덮어쓰기`나 `바깥 글 불러오기` 중에서 고릅니다.
- 저장하지 않은 글이 있는 채로 목록으로 나가려 하면 한 번 더 묻습니다.
- `삭제`는 확인 줄이 뜨고, 확인하면 그 파일을 지웁니다(휴지통으로 가지 않습니다).

### PO에게 보내기

고치는 화면의 `PO에게 보내기` 버튼은 저장된 메모를 PO 터미널 입력으로 보냅니다.

1. 저장하지 않은 글이 있으면 먼저 저장하라고 알려 줍니다.
2. 확인 줄에 **받을 PO 주소**가 보입니다. `보내기`를 눌러야 갑니다.
3. 보내는 글은 `메모 요청: <제목> — <본문> (파일: <경로>)` 한 줄입니다. 줄바꿈은 ` ⏎ `로 접히고, 본문이 1500자를 넘으면 잘라 `…(이하 생략, 파일 참고)`를 붙입니다. 파일 경로는 항상 붙으니 PO가 나머지를 읽을 수 있습니다.
4. 받을 PO는 `role=po` 라벨이 붙은 터미널입니다([inbox](inbox.md)의 이름 규칙과 같습니다). PO가 없거나 둘 이상이거나, PO가 일하는 중이면 보내지 않고 이유를 알려 줍니다.

### 바로가기 키

탭 줄에 `메모` 버튼이 생깁니다. 키는 `keys.json`에 직접 더합니다(설치기는 `keys.json`을 건드리지 않습니다).

```json
{
  "cmd-shift-m": "tabs-mine.memo-new",
  "cmd-alt-m": "tabs-mine.memo"
}
```

- `tabs-mine.memo-new`: 패널을 열고 새 메모 화면으로 갑니다.
- `tabs-mine.memo`: 패널을 열고 목록으로 갑니다.
- 모드 이름이 `memo`가 아니라 `tabs-mine`인 것은, 키가 화면에 보이는 모드에만 닿는데 닫힌 패널은 보이지 않기 때문입니다. 늘 보이는 탭 줄이 받아서 패널을 열어 줍니다.

## 필요한 것

- Node.js
- 함께 설치되는 모드: [패널 버튼](tabs-mine.md)

## 설치

추가 모드라 기본 설치에는 들어가지 않습니다.

```sh
curl -fsSL https://raw.githubusercontent.com/xowjd913/agent-mods/main/herdr/install.sh | sh -s -- --add memo
```

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/xowjd913/agent-mods/main/herdr/install.ps1))) -Add memo
```

- 오른쪽 패널에 `memo-board`가 더해지고 탭 줄에 `메모` 버튼이 생깁니다.
- 폴더 설정은 `<설정 폴더>/memo/config.json`에 있습니다. `--remove memo`는 모드 폴더와 패널의 `memo-board`를 빼고, 설정과 **메모 파일은 남깁니다.**
- 빼는 방법과 다른 옵션은 [모드 골라 설치](../../herdr/README.md#모드-골라-설치)에 있습니다.

## 확인하지 못한 것

자동 시험은 파일 이름·제목·목록·PO 글 만들기와 설치기를 확인합니다. 아래는 실제 앱 화면에서 사람이 눌러 봐야 합니다.

- 글쓰기 칸의 입력과 저장·충돌 안내 줄이 보이는 모양
- 폴더 고르기 창과 Google Drive 동기화 폴더 선택
- `PO에게 보내기`가 실제 PO 터미널에 들어가는지
- `cmd-shift-m`·`cmd-alt-m` 키가 패널을 여는지, 탭 줄 `메모` 버튼 모양
