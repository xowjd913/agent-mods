# 계정 패널 (gh-accounts)

스페이스에서 쓰는 저장소마다 어떤 GitHub 계정을 쓸지 보고 고릅니다. 고른 계정은 [gh-account](../gh-account.md) 도구가 모든 터미널의 `gh` 명령, `git push` 인증, 커밋 작성자에 씁니다.

오른쪽 패널의 `계정`을 누르면 위에서 아래로 설치 상태, 고른 저장소의 계정 확인, 저장소 owner별 계정 선택, 로그인된 계정, 규칙 목록이 차례로 나옵니다. 아래 "사용법"이 각 칸을 설명합니다.

## 사용법

- **위치**: 오른쪽 패널(탭 줄의 `계정` 버튼)
- **맞는 사람**: 회사 계정과 개인 계정처럼 GitHub 계정을 여럿 쓰는 사람

### 설치

- [gh-account](../gh-account.md) 도구(gh 래퍼, git 자격 증명 도우미, 커밋 신원 설정)가 설치돼 있는지 보여 줍니다. 설치하지 않으면 규칙을 정해도 `gh`·`git`이 쓰지 않습니다.
- `설치…`를 누르면 바뀔 파일과 git 전역 설정을 먼저 보여 줍니다. `설치하기`를 눌러야 바꿉니다. 이 도구가 만들지 않은 `gh` 파일이 이미 있으면 설치하지 않습니다.
- `원래대로 되돌리기…`도 지울 것을 먼저 보여 주고, `되돌리기`를 눌러야 지웁니다. 매핑 파일은 남깁니다.
- 설치한 파일이 바뀌었거나 이 패널과 버전이 다르면 `업데이트…`가 보입니다. 래퍼가 PATH 에서 진짜 `gh`보다 뒤에 있거나 git 이 낮으면 `주의:`로 알려 줍니다.

### 이 저장소는 어느 계정?

- 스페이스 폴더나 찾은 저장소를 고르거나, 폴더 경로(`~/...` 가능)나 `owner/repo`를 적고 `확인`을 누릅니다.
- 그 저장소의 `gh` 명령, `git push` 인증, 커밋 신원이 각각 어느 계정을 쓰는지와 그 이유를 보여 줍니다.
- `접속 시험`은 그 계정으로 GitHub 에 접속해 로그인 이름과 그 저장소 권한(관리자·push 가능·읽기만)을 보여 줍니다. 아무것도 바꾸지 않고, 토큰은 보여 주지 않습니다.
- 로그인된 계정의 개인 저장소(`acct-a/...`)가 다른 계정에 매핑돼 있으면 `주의:`로 알려 줍니다.
- 커밋 신원은 git 이 실제로 읽은 신원 파일의 계정으로 보여 줍니다. 그 계정이 매핑 계정과 다르면 `주의:`로 알리고 `gh-account sync`를 권합니다.

### 저장소 owner

- 모든 스페이스 폴더와, 각 스페이스 탭에 열린 터미널의 지금 폴더에서 github.com 원격이 있는 저장소를 찾습니다. 폴더가 같은 스페이스는 한 번만 봅니다.
- 찾은 저장소를 주인(owner)별로 한 줄에 묶습니다. 같은 owner 는 스페이스가 여럿이어도 한 줄입니다.
- owner 마다 쓸 계정을 고릅니다. 고르면 `owner/*` 규칙을 만들거나 바꿉니다. `규칙 없음`을 고르면 그 규칙을 지웁니다.
- 저장소 목록은 접혀 있습니다. owner 줄을 누르면 펼쳐서 저장소마다 실제로 쓰일 계정과 이유(기본 계정, 다른 규칙, 로그인된 계정의 저장소)를 보여 줍니다.
- 로그인된 계정과 이름이 같은 owner(예: `acct-a/*`)의 저장소가 다른 계정을 쓰면 owner 줄 아래에 `주의:` 줄을 보여 줍니다.
- 규칙은 스페이스가 아니라 owner 기준입니다. 같은 owner 저장소를 다른 스페이스에서 열어도 같은 계정을 씁니다.

### 기본 계정

규칙에 없는 저장소에 쓸 계정입니다. `없음`이면 gh 활성 계정을 그대로 씁니다.

- 로그인된 다른 계정의 저장소(예: 기본 계정이 `acct-b`일 때 `acct-a/notes`)에는 기본 계정을 쓰지 않고 그 계정을 씁니다. 개인 저장소가 다른 계정으로 push 되지 않게 하려는 것입니다.
- 계정을 고르면 바로 바꾸지 않고, 찾은 저장소 중 그 계정을 쓰게 될 저장소와 그대로 둘 저장소를 먼저 보여 줍니다. `바꾸기`를 눌러야 바꾸고, `취소`하면 그대로 둡니다. `없음`은 바로 바꿉니다.

### 로그인된 계정

gh 에 로그인된 github.com 계정입니다.

`계정 추가…`로 터미널 없이 계정을 더합니다.

1. 안내를 읽고 `시작`을 누릅니다.
2. 일회용 코드가 보이면 `코드 복사`를 누르고, `브라우저 열기`로 GitHub 에 더할 계정으로 로그인해 코드를 넣습니다.
3. 승인하면 패널이 저절로 끝나고 계정 목록을 다시 읽습니다. `그만두기`로 중간에 멈출 수 있고, 15분이 지나면 저절로 멈춥니다.

- `gh auth login`은 로그인이 끝나면 새 계정을 gh 활성 계정으로 바꿉니다. 패널은 시작할 때의 활성 계정을 기억해 두었다가 그 직후 `gh auth switch`로 한 번 되돌립니다. 패널이 활성 계정을 바꾸는 것은 이때뿐입니다.
- 그래서 다른 세션이 `gh` 명령이나 `git push`를 하는 중에는 누르지 마세요. 되돌리기 전 잠깐 동안 그 세션들이 새 계정을 쓸 수 있습니다.
- 되돌리지 못하면 터미널에서 실행할 `gh auth switch` 명령을 보여 줍니다.
- 로그인이 끝나면 새 계정의 커밋 신원도 바로 맞춥니다(`gh-account sync`). gh-account 도구가 설치돼 있을 때만 합니다. 설치 전이나 되돌린 뒤에는 매핑 파일이 남아 있어도 git 설정을 건드리지 않습니다. 맞추지 못하면 터미널에서 `gh-account sync`를 실행하라고 알립니다.
- 토큰은 gh 가 보관합니다. 패널은 토큰을 읽거나 보여 주지 않습니다.

### Claude 계정

Claude 계정을 여럿 쓰는 사람을 위한 칸입니다. GitHub 칸과 따로 움직이고, 위 설명은 그대로입니다. 터미널을 열 필요가 없습니다.

- **줄**: `기본 계정`과 더한 계정마다 한 줄입니다. 이름, 로그인 여부(`로그인됨`·`로그인 안 됨`), 사용량(`5h 42% · 7d 7%`)을 보여 줍니다. 로그인 여부는 5분마다만 다시 확인합니다(그릴 때마다 읽지 않습니다).
- **새 세션에 사용**: 줄 앞의 동그라미로 고릅니다. 지금 돌고 있는 세션은 그대로이고, **새로 여는 세션부터** 적용됩니다. `기본 계정`을 고르면 `CLAUDE_CONFIG_DIR`를 정하지 않은 평소 상태입니다. 아직 로그인되지 않은 계정을 고르면 "새 세션이 로그인 화면에서 멈출 수 있습니다"라는 경고를 함께 보여 줍니다.
- **계정 추가…**:
  1. 이름(예: 회사, 개인)을 적고 `추가`를 누릅니다. `~/.claude-accounts/<id>` 폴더를 만들고(권한 0700), `CLAUDE.md`·`settings.json`·`skills`·`hooks`·`plugins`·`output-styles`·`keybindings.json`·`my-mods`·`dev-mods`·`po-slack-webhook`을 `~/.claude`에서 링크해 둡니다(없는 것은 건너뜀). `.claude.json`·`projects`·`sessions`·캐시·`usage-limits.json`은 공유하지 않습니다.
  2. 백그라운드 터미널에서 `claude auth login --claudeai`가 돕니다. 로그인 주소가 보이면 `주소 복사`를 누르고 **시크릿 창(Cmd+Shift+N, Windows는 Ctrl+Shift+N)에서** 엽니다. 기본 브라우저 창은 이미 다른 계정으로 로그인돼 있을 수 있기 때문입니다.
  3. 끝나면 `성공`·`실패`를 보여 줍니다. `그만두기`로 멈출 수 있고, 15분이 지나면 저절로 멈춥니다.
  4. 새 계정이 기본 계정이나 이미 등록한 계정과 같은 계정이면 `이미 등록된 계정과 같음`이라고만 알립니다. 같은 계정인지 확인하려고 계정 ID를 읽어 해시로만 비교합니다. 저장하거나 보여 주지 않습니다(각 폴더의 `.claude.json`에서 `oauthAccount.accountUuid` 한 칸만 메모리에서 읽고 바로 해시하며, 다른 값은 읽지 않습니다).
- **로그아웃…**: 그 계정 폴더로 `claude auth logout`을 실행합니다. 눌러야 합니다.
- **목록에서 빼기…**: 목록에서만 뺍니다. 폴더(`~/.claude-accounts/<id>`)는 지우지 않습니다. 로그인 중인 계정은 뺄 수 없습니다.
- 사용량 위치가 계정마다 다릅니다. 그 폴더의 `usage-limits.json`이 있고 10분 안에 갱신됐을 때만 보입니다.
- 한도에 닿아도 계정을 **저절로 바꾸지 않습니다**. 바꾸는 것은 항상 위의 `새 세션에 사용`입니다.
- Windows에서는 폴더 링크가 막혀 있으면 폴더는 정션, 파일은 복사로 대신합니다(복사한 파일은 `~/.claude` 쪽을 고쳐도 따라가지 않습니다). Windows에서는 Claude 계정의 `새 세션에 사용`, `계정 추가`, `로그인`을 막고 "Windows에서는 아직 지원하지 않습니다(이슈 #121 후속)"라고 안내합니다(기본 계정으로 되돌리기만 됩니다). 예약 실행도 Windows에서는 고른 계정을 적용하지 않고, 적용하지 못했다는 경고를 기록에 남깁니다.

계정 정보는 `~/.herdr-inbox/claude-accounts.json`(`{accounts:[{id,label,dir}], selected}`)에 이름·폴더·선택만 저장합니다. 토큰, 이메일, 계정 ID와 그 해시는 저장하지 않습니다. 로그인 중에만 `~/.herdr-inbox/claude-login.json`(권한 0600)에 로그인 주소와 진행 상태를 두고, 로그인이 끝나거나 취소되면 지웁니다.

**어디에 적용되나요**

- **새 팀원**: `herdr-team.sh spawn`은 부르는 리더 자신의 `CLAUDE_CONFIG_DIR`가 있으면 그것을, 없으면 책상에서 고른 계정을 따릅니다(agent-playbook 쪽 변경, 별도 PR). 리더의 값은 한 글자도 바꾸지 않고 그대로 넘깁니다(macOS 키체인 이름이 그 문자열로 정해지기 때문입니다). 규칙은 이 패치 한 곳에만 있고, 값이 `~/.claude-accounts/<id>` 꼴이 아니거나 `..`이 들어 있거나 선택 파일을 읽지 못하면 기본 계정으로 시작하며 "계정 선택을 읽지 못해 기본 계정으로 시작합니다"를 한 줄 출력합니다. 예약 실행도 같은 이유로 기록의 메모에 같은 줄을 남깁니다.
- **스케줄**: 새로 시작하는 claude 스케줄 세션은 책상에서 고른 계정으로 시작합니다.
- **받은 글 카드**: `이 세션 계정: 회사`처럼 그 세션의 계정을 보여 줍니다(기본은 `기본`). 알 수 없는 폴더는 폴더 이름만 보여 줍니다.
- **아직 따라가지 않는 것**: 손으로 시작한 PO·claude는 `CLAUDE_CONFIG_DIR`를 직접 주지 않으면 기본 계정을 씁니다. 받은 글의 사용률 줄, `usage-status`, `leader-tabs`, `work`의 `collect.cjs`는 아직 `~/.claude`만 읽습니다.

### 규칙

- 위에서부터 먼저 맞는 규칙이 이깁니다. `owner/repo` 규칙은 `owner/*`보다 위에 두세요.
- `↑`·`↓`로 순서를 바꾸고, `✕`로 지웁니다.
- 아래 줄에 `owner/*`나 `owner/repo`를 적고 계정을 골라 `추가`하면 규칙을 더합니다. 같은 규칙이 있으면 계정만 바꿉니다.
- 로그인되지 않은 계정에 매핑돼 있으면 바꾼 뒤 `주의:` 안내를 보여 줍니다. 그 저장소의 `gh`·`git push`는 다른 계정으로 넘어가지 않고 실패합니다.

패널은 60초마다, 그리고 무언가 바꿀 때마다 다시 읽습니다. 터미널에서 `gh-account`로 바꾼 것도 같은 파일이라 함께 보입니다.

## 필요한 것

- 함께 설치되는 모드: `tabs-mine`
- [gh-account](../gh-account.md) 도구: 패널과 함께 복사됩니다. 실제로 쓰이게 하는 설치는 패널의 `설치…` 버튼이나 `sh herdr/install.sh --gh-account`로 합니다.
- Node.js, gh 2.60 이상
- Claude 계정 칸: `claude` 명령과 `hc`(Herdr 터미널 도구)가 PATH 에 있어야 합니다.
- macOS·Linux. Windows는 gh-account 도구가 아직 지원하지 않습니다.

## 설치

추가 모드라 기본 설치에는 들어가지 않습니다.

```sh
sh herdr/install.sh --add gh-accounts  # 패널 (저장소 안에서)
```

- 설치하면 오른쪽 패널에 `accounts-board`를 더하고, 탭 줄에 `계정` 버튼이 생깁니다.
- 그다음 패널의 `설치…` 버튼으로 gh-account 도구를 설치합니다. 터미널에서 `sh herdr/install.sh --gh-account`로 해도 같습니다.

빼는 방법과 다른 옵션은 [모드 골라 설치](../../herdr/README.md#모드-골라-설치)에 있습니다.
